# Producción asistida de regalos — checklist interno

**Estado:** soporte operativo del equipo listo para integrar; migración del circuito del comprador **pendiente**. Este documento no autoriza anuncios ni modifica pagos, derechos de acceso o modelos comprados.

## Principio comercial confirmado

Para experiencias digitales personalizadas, el cliente elige un modelo, deja correo y WhatsApp, paga por Mercado Pago y **el equipo** recoge textos/fotos/audios/fechas, personaliza exactamente las variables permitidas y entrega el enlace privado. No debe rediseñarse la escena ni la animación del modelo comprado.

Los juegos digitales vendidos como acceso directo tienen un circuito diferente y no deben confundirse con experiencias a preparar.

## Trabajo del equipo para cada compra

1. **Verificar acreditación:** usar `/admin/operaciones`; no confundir un pedido creado ni un histórico marcado como aprobado con un pago verificado.
2. **Contactar:** usar el correo o WhatsApp del comprador, registrar el seguimiento mediante “Marcar como contactado”. No enviar una imagen/publicación genérica a modo de regalo personalizado.
3. **Reunir materiales:** solicitar únicamente lo definido por el modelo: nombre del emisor/destinatario, textos, recuerdos, fotografías, audios y fechas. Verificar consentimiento para compartir material personal. No fijar un plazo de entrega sin una política operativa aprobada.
4. **Editar únicamente el contenido:** desde el vínculo **Preparar en editor privado**, conservar `experience_slug`, `template_version` y el recorrido fijado para la compra. La administración ya dispone de campos, escenas y recursos multimedia; auditar compatibilidad por experiencia.
5. **Revisar en móvil:** desde **Revisar vista previa**, comprobar fotos, audio, frases, contraste, interacción táctil, enlaces y escena final.
6. **Publicar y entregar:** solo con resultado aprobado y datos correctos. Compartir el enlace de esa instancia, no una demo ni un vínculo de edición.
